Core Hardware & Software

Small technology.
Big peace of mind.

Built with precision hardware components engineered for ultra-low power consumption and zero-latency detection.

RFID

Identifies your essentials without batteries. Tiny passive sticker tags last indefinitely on laptops, ID cards, and keys.

ESP32

The brain connecting the bag to the digital world. Features deep sleep mode to run for weeks on a single recharge.

Wi-Fi & BLE

Keeps the system connected. Synchronizes telemetry via Web Bluetooth and home Wi-Fi gateways seamlessly.

Smart App

Shows what's present and what's missing in real time. Provides custom packing profiles for work, college, and travel.

Magnetic Trigger

Reed switch sensor wakes the microcontroller on zipper closure, eliminating the need to press any manual scan buttons.

USB-C Power

Rechargeable 3.7V Li-Po battery charged via standard USB Type-C with built-in TP4056 overcharge protection.
